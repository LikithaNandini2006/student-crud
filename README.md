# 🎓 Student Management System

A simple and efficient **Student Management System** built using **Flask, HTML, CSS, SQLite, and SQLAlchemy**. This web application allows users to perform CRUD (Create, Read, Update, Delete) operations on student records through a clean and user-friendly interface.

---

## 📌 Features

- ➕ Add New Students
- 📋 View Student Records
- ✏️ Update Student Information
- 🗑️ Delete Student Records
- 💾 SQLite Database Integration
- 🌐 Flask Backend
- 🎨 Responsive HTML & CSS Frontend

---

## 🛠️ Technologies Used

- Python
- Flask
- SQLAlchemy
- SQLite
- HTML5
- CSS3

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/student-management-system.git
```

### Navigate to Project Directory

```bash
cd student-management-system
```

### Install Required Packages

```bash
pip install flask flask-sqlalchemy
```

### Run the Application

```bash
python app.py
```

---

## 🚀 Usage

1. Open your browser.
2. Visit:

```text
http://127.0.0.1:5000
```

3. Add, edit, view, and delete student records.
